# DJ TOTE Official Website (本番版・確認用 v1)

名刺と同じ、白背景＋シアン／ピンク／青紫のRGBグラデーションを用いた静的サイト。

## コンテンツ

- TOP — 初期版採用のリボンロゴ（RGB）
- NEXT GIG — 2026年11月15日、月あかり夢てらす20周年DAY3（終了後は「準備中」に自動切替）
- PROFILE — DJ とての紹介、2019年の既存プロフィール写真（要最終確認）
- BECONE — 2010–2025の活動紹介、本人のnote記事リンク
- GIG ARCHIVE — Googleスプレッドシート「とて DJ出演履歴」から抽出した244件（2026-10-22時点）
- CONTACT — Xアカウントへの導線（フォームは未設置）

## 注意

- **本番サイトの `main` はまだ変更していません。** 確認後に更新してください。
- `data/gigs.json` はスプレッドシートの**静的スナップショット**です。シートの更新は自動反映されません。
- XリンクはXの公開プロフィールに移動します。DMやお問い合わせフォームの利用可否は別途確認してください。
- 2019年のプロフィール写真を使っています。公開前に最新画像への交換希望を確認してください。
- 元CSVの「備考」は個人的な注記の可能性を考えて公開データから除いてあります。
- `data/gigs.json` は `main.js` から `fetch()` しているため、ローカルではファイルをダブルクリックするのではなくローカルHTTPサーバーで確認してください。

## ローカルプレビュー

このフォルダで `python -m http.server 8000` を実行し、ブラウザで `http://localhost:8000` を開く。

## 公開

GitHub `dj-tote/dj-tote-site` の別ブランチにファイルを配置 → GitHubでプルリクエスト → Cloudflare Pagesのプレビューを確認 → 問題なければ `main` にマージ。`main` の更新後はCloudflare Pagesが自動で再公開します。
